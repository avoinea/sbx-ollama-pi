If you run `git diff develop` or `git diff master`, what do you think about these changes. Are they safe to merge and deploy in production? Do you see any edge cases or fallback issues and backward incompatibility that can lead to website crash? 

You can also use gh cli to view open PRs. 

Always look into current workspace. If I provide a path, it should always be relative to the current workspace.
